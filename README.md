# LAN Setup and Switch Operations

## Overview
This repository demonstrates hands-on experience with **local area networks (LANs)**, focusing on switch operations, MAC address learning, subnetting, and privilege levels in Cisco IOS.

## Key Activities
- Created a LAN topology with multiple computers connected via a switch
- Assigned IP addresses and subnet masks to hosts, ensuring proper connectivity
- Observed how switches dynamically learn MAC addresses as devices communicate
- Tested connectivity within the same subnet and explored limitations across subnets
- Explored Cisco IOS privilege levels and created user accounts with custom access rights
- Practiced commands such as `show interfaces status`, `show mac-address-table`, `ping`, and privilege management

## Tools Used
- Cisco Packet Tracer (`.pkt` file included)
- Cisco IOS command-line interface simulation


## Key Learnings
- Understanding MAC address tables and VLANs
- Practical subnetting and network communication
- Switch port management and dynamic MAC learning
- Cisco IOS privilege levels and user access control

## How to Use
1. Clone the repository
2. Open the `.pkt` file in **Cisco Packet Tracer**
3. Follow the topology to explore switch operations, IP addressing, and connectivity
4. Use the included commands to practice privilege level management
